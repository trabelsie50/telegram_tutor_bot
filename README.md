# 🤖 telegram_tutor_bot

> بوت تيليغرام تعليمي تفاعلي ذكي لتلاميذ السنة الخامسة ابتدائي في تونس، مبني على المنهج المدرسي الرسمي (المركز الوطني البيداغوجي - CNP).

---

## 📖 نظرة عامة على المشروع

يُعدّ هذا المشروع بوتًا تعليميًا متكاملًا يعمل على منصة تيليغرام، مصمّمًا ليقوم بدور **أستاذ خصوصي تفاعلي** لتلاميذ السنة الخامسة ابتدائي في تونس. يتقمّص البوت شخصية **"الأستاذ المتميز"** — أستاذ تونسي مبدع، مشجّع، ومتقن للمنهج — مع الالتزام الصارم بالمنهج المدرسي الرسمي الصادر عن المركز الوطني البيداغوجي (CNP).

### الميزات الرئيسية

| الميزة | الوصف |
|--------|-------|
| 🎓 **شرح الدروس** | شرح نصي وصوتي للدروس حسب المنهج التونسي |
| 📝 **الاختبار الذكي** | توليد 3 أسئلة متدرجة الصعوبة مع تقييم فوري وتشجيع |
| 👨‍👩‍👧 **تقارير الأولياء** | ملخصات أداء مبسطة تُرسَل لأولياء الأمور عبر تيليغرام |
| 🔍 **وضع المراجعة** | مراجعة إلزامية لنصوص OCR قبل اعتمادها في قاعدة المعرفة |
| 🗣️ **دعم صوتي** | تحويل الصوت إلى نص (Whisper محلي) وتحويل النص إلى صوت (gTTS) |
| 📚 **نظام RAG محلي** | ChromaDB مع نماذج تضمين محلية لضمان دقة الإجابات المنهجية |

### نبذة تقنية

- **لغة البرمجة:** Python 3.10+
- **إطار البوت:** python-telegram-bot v20+
- **نموذج اللغة:** OpenAI (GPT-4/3.5)
- **قاعدة المعرفة:** ChromaDB (محلي) + نماذج التضمين (sentence-transformers)
- **قاعدة البيانات:** SQLite (تتبع التقدم والأخطاء)
- **OCR:** Tesseract / EasyOCR (استخراج نصوص من صور الكتب)
- **تحويل الصوت:** Whisper محلي (Open Source) + gTTS (للرد الصوتي)

## 🌐 متطلبات البيئة

قبل البدء، تأكد من توفر المتطلبات التالية:

### متطلبات النظام

- **Python** 3.10 أو أحدث
- **نظام التشغيل:** Linux (موصى به للخادم السحابي)، Windows، أو macOS
- **مكتبات النظام:**
  - `tesseract-ocr` (محرك OCR) — مع دعم اللغة العربية (`tesseract-ocr-ara`) والفرنسية (`tesseract-ocr-fra`)
  - `ffmpeg` (لمعالجة الملفات الصوتية)

### متطلبات خارجية

- **حساب OpenAI** مع مفتاح API صالح (للوصول إلى GPT-4/3.5)
- **حساب تيليغرام** مع بوت مسجّل عبر [@BotFather](https://t.me/BotFather)
- **نموذج Whisper محمّل مسبقًا** (حجم `small` أو أكبر) — يعمل بالكامل بدون إنترنت

### تثبيت متطلبات النظام (Ubuntu/Debian)

```bash
# تثبيت Tesseract OCR مع دعم العربية والفرنسية
sudo apt-get update
sudo apt-get install -y tesseract-ocr tesseract-ocr-ara tesseract-ocr-fra

# تثبيت ffmpeg
sudo apt-get install -y ffmpeg

# تثبيت Python 3.10+ (إن لزم)
sudo apt-get install -y python3.10 python3.10-venv python3.10-dev
```

### تثبيت Whisper محلي

```bash
# تثبيت مكتبة openai-whisper
pip install openai-whisper

# تحميل نموذج Whisper (حجم small كمثال — ~1 جيجابايت)
whisper --download-model small
```

## ⚙️ إعداد المشروع

### 1. استنساخ المستودع

```bash
git clone https://github.com/<username>/telegram_tutor_bot.git
cd telegram_tutor_bot
```

### 2. إنشاء بيئة افتراضية وتفعيلها

```bash
python3.10 -m venv venv
source venv/bin/activate  # على Linux/macOS
# أو: venv\Scripts\activate  # على Windows
```

### 3. تثبيت المكتبات المطلوبة

```bash
pip install -r requirements.txt
```

> **ملاحظة:** ملف `requirements.txt` يتضمن المكتبات التالية:
> - `python-telegram-bot>=20.0` — إطار بوت تيليغرام
> - `openai` — واجهة API OpenAI
> - `chromadb` — قاعدة بيانات المتجهات (RAG)
> - `sentence-transformers` — نماذج التضمين المحلية
> - `pytesseract` — واجهة Python لـ Tesseract OCR
> - `easyocr` — محرك OCR بديل يدعم العربية والفرنسية
> - `openai-whisper` — تحويل الصوت إلى نص (محلي)
> - `gTTS` — تحويل النص إلى صوت
> - `Pillow` — معالجة الصور
> - `langchain` — إطار التطبيقات اللغوية
> - `langchain-openai` — تكامل Langchain مع OpenAI
> - `python-dotenv` — إدارة متغيرات البيئة

### 4. إعداد متغيرات البيئة

أنشئ ملف `.env` في مجلد المشروع الجذري:

```bash
cp .env.example .env
nano .env  # أو أي محرر نصوص تفضله
```

ثم املأ المتغيرات التالية:

```env
# ========================================
# إعدادات بوت تيليغرام
# ========================================
TELEGRAM_BOT_TOKEN=1234567890:ABCDefghIJKLmnopQRSTuvwxYZ

# ========================================
# إعدادات OpenAI
# ========================================
OPENAI_API_KEY=sk-xxxxxxxxxxxxxxxxxxxxxxxxxxxxxxxx

# ========================================
# إعدادات RAG (ChromaDB)
# ========================================
CHROMA_PATH=./chroma_db

# ========================================
# إعدادات Whisper (محلي)
# ========================================
WHISPER_MODEL_SIZE=small

# ========================================
# إعدادات OCR
# ========================================
OCR_ENGINE=tesseract

# ========================================
# إعدادات عامة
# ========================================
DEFAULT_LANGUAGE=ar
```

| المتغير | الوصف | القيم المقترحة |
|---------|-------|----------------|
| `TELEGRAM_BOT_TOKEN` | توكن البوت من BotFather | سلسلة نصية |
| `OPENAI_API_KEY` | مفتاح API من OpenAI | سلسلة نصية تبدأ بـ `sk-` |
| `CHROMA_PATH` | مسار تخزين قاعدة ChromaDB | مسار مجلد |
| `WHISPER_MODEL_SIZE` | حجم نموذج Whisper | `tiny`, `base`, `small`, `medium`, `large` |
| `OCR_ENGINE` | محرك OCR المستخدم | `tesseract` أو `easyocr` |
| `DEFAULT_LANGUAGE` | لغة الافتراض للبوت | `ar` (عربية), `fr` (فرنسية) |

### التأكد من البيئة

قبل التشغيل، تحقق من أن جميع المكونات جاهزة:

```bash
python main.py --check-env
```

هذا الأمر يتحقق من:

- توفر نموذج Whisper محمّلًا
- إمكانية الوصول إلى Tesseract OCR
- وجود مجلدات المشروع المطلوبة

```bash
python main.py
```

أو:

```bash
python main.py --run
```

## 🎮 الأوضاع التفاعلية

بعد بدء المحادثة مع البوت، يمكن للتلميذ استخدام الأوضاع التالية:

### 🏠 الشاشة الرئيسية

عند البدء، يرحب البوت بالتلميذ ويعرض له اختيار المادة الدراسية عبر أزرار تفاعلية:

- 🔢 **رياضيات**
- 📖 **فرنسية**
- 📝 **عربية**
- 🔬 **إيقاظ علمي**

### 📖 وضع شرح الدروس

يختار التلميذ المادة ثم الدرس المحدد، فيقوم البوت بـ:

1. استرجاع النص المنهجي من ChromaDB عبر نظام RAG
2. تقديم شرح مبسط مع أمثلة من الواقع المعيش في تونس
3. تقديم الشرح بصوتيًا عبر gTTS عند الطلب

**لغة الشرح:** فصحى مبسطة للدروس العلمية والعربية، فرنسية لمادة الفرنسية، مع لمسات من الدارجة التونسية للتشجيع والتبسيط.

### 📝 وضع الاختبار الذكي (Smart Quiz)

1. يختار التلميذ الدرس المراد اختباره
2. يولّد البوت **3 أسئلة متدرجة الصعوبة** (سهل → متوسط → صعب)
3. كل سؤال مرتبط مباشرة بنص الدرس المسترجع من RAG
4. يتم تقييم الإجابات فورًا مع التوضيح والتشجيع
5. تُسجَّل النتائج وأنواع الأخطاء في قاعدة SQLite

**مثال على التقييم:**
```
✅ إجابة صحيحة! أحسنت يا بطل! 🎉
❌ إجابة خاطئة — لا تقلق، الإجابة الصحيحة هي: ...
   💡 التلميح: تذكّر ما شرحناه في الدرس...
```

### 👨‍👩‍👧 وضع تقارير الأولياء

يمكن لأولياء الأمور طلب تقرير أداء أبنائهم عبر تيليغرام:

- ملخص أداء مبسّط (عدد الأسئلة الصحيحة/الخاطئة)
- أنواع الأخطاء الشائعة (مثل: أخطاء في الضرب، أخطاء في التصريف)
- توصيات موجزة للمتابعة

### 🔍 وضع المراجعة (Review Mode)

يُفعَّل تلقائيًا عند استخراج نصوص جديدة من صور الكتب المدرسية:

1. يستخرج البوت النص من الصورة عبر Tesseract/EasyOCR
2. يُرسَل النص المستخرج والصورة الأصلية إلى المشرف على تيليغرام
3. يختار المشرف:
   - **✅ اعتماد** — يُخزَّن النص نهائيًا في ChromaDB
   - **✏️ تعديل** — يكتب المشرف النص الصحيح يدويًا كرد، ويُخزَّن النص المُصحَّح في ChromaDB
4. فقط النص المعتمد يُصبح متاحًا للتلاميذ

> ⚠️ **هذا الوضع إلزامي** لضمان دقة المحتوى التعليمي ومنع انتقال أخطاء الاستخراج (أرقام، معادلات، رموز) إلى التلاميذ.

## 📊 تتبع التقدم والأخطاء

يحتفظ SQLite بتفاصيل دقيقة عن أداء كل تلميذ:

| الجدول | المحتوى |
|--------|---------|
| `students` | بيانات التلاميذ (الاسم، الصف، المادة) |
| `quiz_results` | نتائج كل اختبار (الدرس، النتيجة، التاريخ) |
| `error_types` | أنواع الأخطاء الشائعة لكل تلميذ (مثلاً: خطأ ضرب، خطأ تصريف) |
| `learning_progress` | تقدم التعلم لكل مادة ودرس |

## 🛠️ نصائح تقنية

### تشغيل Whisper محلي على خادم سحابي مجاني

نموذج Whisper يعمل بالكامل بدون اتصال بالإنترنت. يُنصح باستخدام خادم سحابي مجاني مثل **Oracle Cloud Free Tier** الذي يوفر موارد كافية (RAM كبيرة، عدة معالجات) لتشغيل Whisper بحجم `small` أو أكبر بسلاسة.

```bash
# التحقق من تحميل النموذج
whisper --model small --help

# تشغيل Whisper على ملف صوتي (للاختبار)
whisper --model small --file audio.mp3 --language ar --output_format txt
```

### إعادة بناء قاعدة ChromaDB

إذا أردت إعادة بناء قاعدة المعرفة من الصفر (مثلاً بعد إضافة دروس جديدة):

```bash
python rag_engine.py --rebuild
```

### التحقق من حالة البوت

```bash
python main.py --check-env
```
